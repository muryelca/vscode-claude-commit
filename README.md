## Features

- One-click commit message generation from the Source Control title bar (sparkle icon).
- Reads your staged diff via the built-in VS Code Git API, no shell execution.
- Output strictly follows Conventional Commits: `type(scope): description`.
- OAuth token resolved from a VS Code setting, an environment variable, or a first-run input prompt (in that order).
- Progress indicator while generating, helpful error notifications, hidden token entry.
- Uses Claude Haiku 4.5 for fast responses with a tight token budget.
- Cross-platform: works wherever VS Code runs (Windows, macOS, Linux).

## How it works

1. The extension calls `repo.diff(true)` on the first repository exposed by the built-in `vscode.git` extension API to read your **staged** changes.
2. The diff is sent to the Anthropic Messages API using the official SDK `@anthropic-ai/sdk@^0.87.0`, with Bearer auth and the `anthropic-beta: oauth-2025-04-20` header (Claude Code OAuth flow).
3. Model: `claude-haiku-4-5-20251001`. `max_tokens: 100`.
4. The response is sanitized through a regex (`/^(feat|fix|chore|docs|refactor|test|style|ci|perf|build|revert)(\([^)]+\))?: .+$/m`) to extract a single Conventional Commit line.
5. The result is written to the Source Control input box (`repo.inputBox.value`), so you can review and commit normally.

## Requirements

- VS Code `>= 1.80.0`.
- A Git repository open in your workspace.
- A **Claude Code OAuth token** (see the next section).
- Node.js is **only** required if you want to build the extension from source.

## Get an OAuth token (`claude setup-token`)

The extension authenticates against the Anthropic API using a Claude Code OAuth token. The recommended way to obtain one is the official Claude Code CLI.

### 1. Install the Claude Code CLI

```bash
npm install -g @anthropic-ai/claude-code
```

Full installation guide: https://docs.claude.com/en/docs/claude-code/overview

### 2. Run `claude setup-token`

```bash
claude setup-token
```

### 3. Authorize in your browser

The command opens a browser window asking you to sign in with your Anthropic account and authorize Claude Code. This requires an Anthropic plan that supports Claude Code (Pro, Max, or Team).

### 4. Copy the token

After authorizing, the CLI prints (and stores) a long-lived OAuth token that begins with `sk-ant-oat01-...`. Copy it. You can regenerate it at any time by re-running `claude setup-token`.

### 5. Provide it to the extension

Use any of the methods in [Configuration](#configuration). The simplest path is to do nothing, run the command in VS Code, and paste the token when the extension prompts you on first use.

## Installation

### From the Marketplace (recommended)

```bash
code --install-extension muryelca.dj-claude-commit
```

Or open the Extensions panel in VS Code and search for **DJ Claude Commit**.

### From a VSIX file

1. Download `dj-claude-commit-<version>.vsix` from the [Releases](https://github.com/muryelcabral/vscode-claude-commit/releases) page.
2. In VS Code: `Ctrl+Shift+P` (`Cmd+Shift+P` on macOS) → **Extensions: Install from VSIX...**.
3. Select the downloaded file.

### From source

```bash
git clone https://github.com/muryelcabral/vscode-claude-commit.git
cd vscode-claude-commit
npm install
npm run compile
npm run package
code --install-extension dj-claude-commit-*.vsix
```

## Configuration

The extension resolves the OAuth token in this priority order:

1. **VS Code setting `claudeCommit.oauthToken`** (recommended).
   Open Settings (`Ctrl+,`), search for **Claude Commit**, and paste your token. Or in `settings.json`:
   ```json
   {
     "claudeCommit.oauthToken": "sk-ant-oat01-..."
   }
   ```

2. **Environment variable `CLAUDE_CODE_OAUTH_TOKEN`**. Useful for shared dev containers or CI-like setups. Must be set before launching VS Code.
   ```bash
   # macOS / Linux
   export CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-...
   ```
   ```powershell
   # Windows PowerShell
   $env:CLAUDE_CODE_OAUTH_TOKEN = "sk-ant-oat01-..."
   ```

3. **First-run prompt**. If neither of the above is set, the extension prompts you the first time you run the command. The entered value is validated to start with `sk-ant-oat`, then stored in your global VS Code settings so you only enter it once.

## Settings reference

| Setting | Type | Default | Description |
|---|---|---|---|
| `claudeCommit.oauthToken` | `string` | `""` | Claude Code OAuth token (`sk-ant-oat01-...`). Falls back to the `CLAUDE_CODE_OAUTH_TOKEN` environment variable when empty. |

## Usage

1. Stage your changes:
   ```bash
   git add <files>
   ```
2. Open the Source Control panel (`Ctrl+Shift+G` / `Cmd+Shift+G`).
3. Click the **✨ sparkle icon** in the Source Control title bar. Alternatively, run **Generate Commit Message (Claude)** from the Command Palette (`Ctrl+Shift+P`).
4. A progress indicator appears in the Source Control area while Claude generates the message.
5. The commit input box is populated with a single Conventional Commit line. Review or edit it, then commit as usual.

## Conventional Commits cheat sheet

Format: `type(scope): description`. The scope is optional.

Supported types: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`, `style`, `ci`, `perf`, `build`, `revert`.

Example outputs:

```
feat(auth): add JWT refresh flow
fix(api): handle null response in user lookup
docs: clarify setup-token instructions
refactor(scm): extract diff resolver
chore(deps): bump anthropic sdk to 0.87.0
```

Spec: https://www.conventionalcommits.org

## Troubleshooting

| Symptom | Cause and fix |
|---|---|
| `No git repository found.` | Open a folder that contains a `.git` directory. |
| `No staged changes. Run git add first.` | The extension only reads the **staged** diff. Run `git add <files>` and try again. |
| `Expected an OAuth token starting with sk-ant-oat...` | The value entered is not a Claude Code OAuth token. Re-run `claude setup-token` and paste the full token. |
| HTTP `401` / `403` from the API | Token expired or revoked. Regenerate it with `claude setup-token` and update the setting. |
| Sparkle icon not visible | Ensure the extension is enabled, reload the window (`Developer: Reload Window`), and confirm the Source Control panel is open. |
| Empty or truncated message | Very large diffs may exceed the 100-token output budget. Stage a smaller chunk of changes and run again. |

## Privacy and security

- Your **staged diff** is sent to Anthropic's API over HTTPS using your OAuth token.
- The token is stored in VS Code's Global state when entered via the first-run prompt. It is never logged, never printed, and never copied to the clipboard by the extension.
- The extension performs **no telemetry, no analytics, and no third-party network calls** other than the request to the Anthropic Messages API.
- For sensitive repositories, review the diff being staged before invoking the command.
